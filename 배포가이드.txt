배포 방법 ① — Vercel (권장, 1분 완료)
================================================================

A) CLI 방식:
   cd "이 폴더"
   npx vercel --prod
   → Project Name: shine-k-insights
   → Deploy

B) 드래그&드롭 방식 (CLI 불필요):
   1. https://vercel.com/new
   2. website/ 폴더 전체를 브라우저에 드래그
   3. Project Name: shine-k-insights
   4. Deploy 클릭

  → 완료: https://shine-k-insights.vercel.app

================================================================
배포 방법 ② — 카페24·후이즈 등 호스팅
================================================================

  1. FTP/SFTP로 모든 파일을 public_html/ 에 업로드
  2. .htaccess 가 적용되는지 확인 (.htaccess Override 옵션)
  3. HTTPS 인증서 활성화 (Let's Encrypt 무료)
  4. PWA·Service Worker는 HTTPS에서만 작동

================================================================
배포 방법 ③ — GitHub Pages
================================================================

  1. GitHub 저장소 생성: shine-k-insights
  2. website/ 폴더 전체를 main 브랜치에 푸시
  3. Settings → Pages → Source: main / root
  4. 완료: https://[username].github.io/shine-k-insights

PWA 설치 안내 (사용자에게 제공)
================================================================

  공유 버튼 → "홈 화면에 추가"

Android (Chrome / Samsung / 화웨이 / 샤오미):
